About this resource · How to use it · Learning engineering connections

What is this resource?

A configurable learning engineering simulation for examining team contributions, coordination, and working conditions across three fictional scenarios. The studio preserves iterations, runs local experiments, replays original journals, and compares separately frozen evidence scorecards. Dry runs are labeled workflow fixtures.

How should I use it?

  1. Apply a scenario and a default team, competency ablation, or individual-agent preset. Inspect the learner target, affected-person constraints, competency personas, environmental conditions, and fixed challenges.
  2. Set the three outcome thresholds, essential criterion floors, and explicit variation assumptions. Save an iteration with a change note before using Review & run to inspect responsibilities and the matched call schedule.
  3. Replay a saved run to inspect prompts, evidence, and artifact revisions. The original declared-design synthetic outcome cards remain separate from the new blind evidence scorecard.
  4. In Scorecard, prepare opaque packets and keep the private assignment key separate. Use the isolated blind workspace to cite evidence, retain unknowns, and freeze all reviews before revealing assignments or comparing candidates within a scenario.
  5. Fork an iteration when changing a team, assumption, or design. Export the preserved snapshot, frozen scorecards, and original journals to retain the complete parent-linked evidence trail.

How does this connect to LENS and learning engineering?

For LENS and learning engineering, the experiment asks whether a competency changes decisions and implementation under specified conditions. Human flourishing, learning sciences, and systems engineering provide complementary foundations. Configured roles are hypotheses about contributions; their presence does not demonstrate human proficiency, learning outcomes, or the validity of a simulated team.
