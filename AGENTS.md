# Required resource guidance

Every new resource page must include the shared, collapsed **About this resource**
card below its introduction and before the activity. Supply its purpose, at least
two practical use steps, and a meaningful connection to LENS and learning engineering.

Follow [.cursor/rules/resource-guidance.mdc](.cursor/rules/resource-guidance.mdc)
for the full requirement and [CLAUDE.md](CLAUDE.md) for existing repository conventions.
The production build and automatically discovered browser tests enforce this rule.
Do not bypass it with broad exceptions or a manually maintained page list.
