About this resource · How to use it · Learning engineering connections

What is this resource?

A flower-based experiment studio and a collection of preserved agent runs on fictional problems. Configure team contributions, examine the original journals and candidate tools, and identify the observations still needed with real learners and practitioners.

How should I use it?

  1. Open Dynamic conversations to configure Design / Develop roles and an editable case, then inspect easy/medium/hard Deploy / Test conditions.
  2. Choose an earlier case and replay its original discussion. Compare a challenge, decision, and artifact; those records retain their original team assignments.
  3. Inspect the requirements and manifest. Name an affected-person review or field observation that could challenge the candidate before use.

How does this connect to LENS and learning engineering?

The flower makes complementary expertise and shared understanding explicit across a learning engineering cycle. LENS connects Human flourishing, Learning sciences, and Systems engineering; the simulation asks how contributions enter decisions and executable designs. Output alone does not demonstrate human capability or learning impact.

From candidate to operational product

Understand → Map → Design → Build → Instrument → Experiment → Evaluate → Refine is a revisitable cycle. Build produces the executable candidate; refinement can return to any invalidated requirement. The learning engineer integrates the work and keeps human and system requirements visible.

Real use needs accountable ownership, affected-person review, appropriate data handling, accessible operation, a meaningful comparison and stopping rules. Learning, workplace transfer and flourishing remain claims to investigate. Inadequate conditions can justify changing the product, changing the work system, or stopping.

The hosted site serves saved products and replay. New model runs use the local runner in this repository; hosted model access and a shared job queue remain future work.
