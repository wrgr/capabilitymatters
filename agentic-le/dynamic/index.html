About this resource · How to use it · Learning engineering connections

What is this resource?

A configurable two-phase tool: dynamic Design / Develop conversations, then Deploy / Test on a frozen learning resource under easy, medium and hard conditions. The public editor changes and exports configurations and reads retained records; model execution uses the local runner.

How should I use it?

  1. Choose a modest case and team condition. Edit the case brief, specialist or generalist knowledge, scenario conditions, and any user change; export the configuration.
  2. Run the exported configuration with the local runner, freeze an artifact version and record the three deployment tests. Import the run to inspect questions, replies, objections and decisions.
  3. Read expert process and result assessments separately. An update produces a new version and another test set; preserve missing evidence and earlier results.

How does this connect to LENS and learning engineering?

The flower organizes complementary expertise around shared understanding. The tool makes that understanding inspectable through actual exchanges and changes to a solution. Human flourishing, Learning sciences, and Systems engineering remain the LENS foundations. Role permissions do not erase model knowledge, and agentic judgments do not establish human learning outcomes.

Give the team a problem, bounded expertise and room to respond to one another. Develop a solution, freeze a version, and test it under easy, medium and hard conditions. An expert evaluator examines the conversation and the result separately.

The conversations are among the agents designing the learning resource. Deployment tests use repeatable scripted browser actions to observe the resulting tool; they do not simulate a learner’s reasoning or measure human learning.
