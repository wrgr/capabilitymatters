# Canonical Capability Matters home

The lifecycle work began as an isolated project in Santiago2 because that was the active workspace. The user directed that the product, standardized roles, code and documentation belong in Capability Matters. This repository is now the canonical implementation.

Current code is in `tools/lifecycle/`; role/framework data in `src/data/lifecycle/`; public guide and role routes in `src/pages/lifecycle-lab/`; replay, saved fictional journals and candidate resources in `public/lifecycle-lab/`; operating documentation in `docs/lifecycle/`. The source and website use Capability Matters' existing GitHub repository and Pages workflow. No replacement site registration is required.

The preserved live exemplar is `20261001T224130Z-live-codex-d6a562`; the scripted exemplar is `20261001T214807Z-scripted-simulation-a23dac`. Their public exports are copied without rewriting event hashes, timestamps, original prompts or provider metadata. Local raw run directories and response caches are preserved under ignored `data/` paths. The historical Santiago2 copy and separate private Site remain an evidence archive, not the current source of truth.

The old live gate was `SANTIAGO2_LIVE`; the canonical runner uses `CAPABILITY_MATTERS_LIVE`. Existing journals retain the historical prompt text. New runs pin versioned inherited roles; older journals explicitly remain legacy fixed-role runs. This migration supplies no new participant observations, human approval or empirical proficiency evidence.
