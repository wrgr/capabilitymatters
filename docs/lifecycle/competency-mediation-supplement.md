## A. Development validation and execution receipts

The complete [latest execution archive](../../experiments/competency-live/2026-11-04/README.md) contains four team episodes, sixteen subagent conversations and thirty-six completed task turns. Those totals include the initial failed logistics pilot. The main paper's analytic set comprises three focal examples, twelve conversations, twenty-seven task turns and nine stress applications. These different denominators are deliberate and are not additional datasets.

The [initial logistics pilot](../../experiments/competency-live/2026-11-04/logistics/evaluation.json) failed its instrument audit because native task bodies were encrypted and the artifact omitted a required descriptive field. Its dialogue and frozen no-release outcome remain intact. A fresh logistics pilot used prospective readable task files before benefits and control-room expansion. The [checkpoint](../../experiments/competency-live/2026-11-04/pilot-validation.json) records that validation sequence. No failed pilot is silently relabeled as an accepted example.

The control-room [gate amendment](../../experiments/competency-live/2026-11-04/controlroom/gate-amendment.json) retains a rejected freeze and subsequent unsuccessful reveal attempt. A validation predicate incorrectly rejected a cautious scope label combined with actual attributed advice. Its correction permits attribution only with an actual delivered-message basis; participant utterances and endorsed draft bytes were unchanged. The independent reviewer accepted the semantics of the actual attributions but did not inspect the implementation within its permitted evidence. The regression tests and software receipts provide separate technical evidence.

Full native public tool records retain participant and reviewer failures, including missing `python` invocations. Root software-validation records retain localhost sandbox failures, a permission-review timeout and an investigator transcript-retention error. These execution details belong here and in their original receipts, not in the main paper's findings.
